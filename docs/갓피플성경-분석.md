# 갓피플성경 분석 (오픈소스 맥 앱을 만들기 위한 조사)

분석 대상: `/Applications/BIBLE.app` — 갓피플성경 26.13 (빌드 26.13.20261008), GODpeople, LTD
분석 날짜: 2026-10-25

## 앱의 정체

- 맥 전용 앱이 아니라 **아이폰·아이패드 앱을 맥에서 돌리는 것** (Apple Silicon의 iOS 앱 실행 기능). `Wrapper/BIBLE.app` 안에 iOS 앱이 들어 있음.
- 최소 iOS 18. 화면은 UIKit `.nib` 75개, 성경 본문은 HTML 템플릿 + jQuery·Swiper를 웹뷰에 띄워서 그림.
- 크기 172MB 중 대부분이 내장 DB `phrase_20261008.sqlite` (161MB).
- Firebase(분석·푸시), Google·네이버·카카오 로그인, 앱 내 구매 영수증 확인이 들어 있음.

## 내장 DB `phrase_20261008.sqlite`

| 테이블 | 행 수 | 내용 |
|---|---|---|
| `bible7_phrase` | 31,105 | 절마다 한 줄. 역본 11개(`km rv ko nw ez wr nv nt es nb kj`)의 소제목(`stitle_*`)·본문 HTML(`phrase_*`)·검색용 글(`search_*`) |
| `bible_code_phrase` | 373,565 | 원어 사전 번호(Strong's, 예: `H7225`)를 낱말에 붙인 데이터 |
| `bible_link_*` | 역본별 0~6만 | 관주·각주(`mark`, `explains`, `link_ids`) |
| `audio_startpoint` | 228,537 | 오디오 성경 파일 안에서 절이 시작하는 시각(초) — 듣기와 본문 강조를 맞추는 데 씀 |
| `unit_jeol_su` | 1,189 | 장마다 절 수 (1,189장) |
| `today_words` | 1,677 | 오늘의 말씀 구절 목록 |
| `tong_read` | 150 | 통독 격려 문구 |
| `one_line_thanks` | 270 | 한 줄 감사 예시 문구 |
| `alarm_pray` | 6 | 기도 알림 문구 |

- 책·장 코드: `unit_code` = 책번호×1000 + 장 (창세기 1장 = `1001`), 구절 아이디 = `창1:1`.
- 본문 HTML 표시: `<h2>` 소제목, `<cite>` 절 번호, `<u class=n>` 각주 번호, `<u class=l>` 관주 표시.
- 오디오 파일 이름 접두어: `ey nb nt nv rv sv wr` (역본별 낭독).

- 오디오 파일 받는 주소(`mp3sec`, `mp3sign` 서명 주소)

## 오픈소스로 만들 때 꼭 지켜야 할 것

1. **본문 DB를 그대로 가져다 쓰면 안 됨.** 내장 DB에 든 개역개정·새번역·쉬운성경·우리말성경·NIV·ESV 등은 성서공회·출판사가 저작권을 가진 역본이고, 갓피플이 사용 허락을 받아 넣은 것. 오픈소스 저장소나 배포판에 넣을 수 없음.
2. 갓피플의 코드·그림·글꼴(SCDream은 유료 글꼴)·문구(통독 격려·감사 문구 등)·이름·로고도 쓰지 않음. 기능만 참고해서 공개된 macOS API로 처음부터 새로 만듦 (OpenCast와 같은 방식).
3. 서버 주소·로그인·동기화 API는 쓰지 않음.
