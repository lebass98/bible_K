# 열린성경 전체 UI·브랜드 시안 · 2026-10-26

## 열기

프로젝트 루트에서 `python3 -m http.server 5175 --directory docs/design`를 실행한 뒤 <http://localhost:5175/preview.html>을 엽니다. 현재 앱 1.3의 메뉴를 기준으로 구성한 독립 HTML 프리뷰입니다. 이번 변경은 `docs/design/`에만 있으며 실제 앱 소스·설치 아이콘·사용자 기록은 바꾸지 않습니다.

## 디자인 방향

열린 책의 페이지가 잎처럼 펼쳐지는 심볼에 빛을 더했습니다. 낮은 채도의 포레스트 그린·세이지와 아이보리 배경을 사용하고, 본문은 넉넉한 행간과 절별 여백으로 읽기 흐름을 만듭니다. 다크 모드는 동일한 정보 위계를 유지합니다.

| 이전 | 시안 | 목적 |
| --- | --- | --- |
| 기능 중심의 단일 목록 | 말씀·묵상·신앙·라이브러리로 메뉴 묶음 | 목적에 맞는 탐색 |
| 동일한 밀도의 본문·도구 | 장 제목·역본·본문·선택 도구를 분리 | 읽기 집중 |
| 흩어진 기록 동작 | 구절 선택→책갈피·노트·카드→내 기록 연결 | 맥락을 유지하는 기록 |
| 일반적인 시작 화면·아이콘 | 책·잎·빛의 동일한 브랜드 모티프 | 앱과 시작 화면의 일관성 |

## 화면 범위

| 화면 | 프리뷰에서 확인할 수 있는 동작 |
| --- | --- |
| 성경 읽기 | 여섯 장 선택·이동, 절 선택, 대역, 글꼴·크기·간격, 라이트·다크, 관주 패널 자리 |
| 말씀 찾기 | 수록된 여섯 장의 낱말 검색·구약/신약 범위·주소 이동 |
| 오늘의 말씀 | 날짜 탐색, 예시 구절 본문 열기·책갈피 |
| 내 기록 | 책갈피·형광펜·묵상 탭, 예시/빈 상태, 저장한 말씀 다시 열기 |
| 읽은 기록 | 날짜별 예시와 프리뷰에서 실제 열어본 장 목록 |
| 통독 계획 | 다섯 계획 선택, 시작 확인, 여섯 예시 분량 체크·진도 갱신 |
| 한 줄 감사 | 입력·공백 검증·세션 목록 추가 |
| 찬송가 | 연습 악보 목록·검색·즐겨찾기·확대·가사 영역·가져오기 안내 |
| 기도 | 제목 추가, 기도 중/응답 상태, 분류 필터 |
| 신앙고백 | 사도신경·주기도문·십계명의 요약형 레이아웃, 글자 크기 |
| 역본 관리 | 역본 카드·가져오기 흐름·프리뷰 기록 JSON 내보내기 |
| 설정 | 본문·모양/글꼴/읽어 주기/알림의 네 탭 |
| 브랜드 | 아이콘·로고 다운로드, 라이트·다크 시작 화면 |
| 말씀 카드 | 본문 선택, 배경·비율·크기 조절, Canvas PNG 내보내기 |

오디오 막대는 재생·속도·위치의 UI 상태만 바뀌고 실제 음원은 재생하지 않습니다. 찬송가 악보는 직접 그린 연습용 레이아웃이며 특정 찬송가 악보가 아닙니다. 신앙고백은 화면 구성을 위한 요약으로 표시했습니다. 시스템 설정·알림·키체인·실제 가져오기/통독/기록 저장은 연결하지 않았습니다. 외부 네트워크 요청이나 개인 기록 수집은 없습니다.

## 검증

- 내장 및 추가 JavaScript 구문 검사 통과.
- 1280×820에서 13개 메뉴 화면 이동·캡처 및 가로 넘침 없음 확인.
- 390×844에서 읽기·말씀·기록·통독·감사·찬송가·기도·신앙고백·역본·설정·브랜드의 가로 넘침 없음 확인.
- 통독 시작→1일차 체크→17% 진도 반영 확인.
- 기도 추가→응답 상태 변경 확인.
- 찬송가 가져오기 대화상자 확인·닫기 확인.
- 설정 탭과 라이트·다크 시작 화면, 말씀 카드 진입 확인.
- 프리뷰 실행 중 브라우저 콘솔 오류 없음 확인.
- 이미지 실제 크기·투명 채널, iconutil의 ICNS 패키징 성공 확인.

## 파일
